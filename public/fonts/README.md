# โฟลเดอร์สำหรับจัดเก็บไฟล์ฟอนต์ (Font Files Directory)

โฟลเดอร์นี้ใช้สำหรับวางไฟล์ฟอนต์ลายมือภาษาไทยทั้ง 8 แบบ สำหรับระบบสลับฟอนต์ลายมือของเว็บไซต์ ART ROOM

## รายชื่อไฟล์ที่ต้องนำมาวางในโฟลเดอร์นี้ (public/fonts/):

1. **แฮมสเตอร์ ( FH Hamsters )**
   - ไฟล์: `FH-Hamsters.ttf` (หรือ `FH-Hamsters.woff2`)
2. **ชีสเค็ม ( Cheesecake )**
   - ไฟล์: `Cheesecake.ttf` (หรือ `Cheesecake.woff2`)
3. **ไข่เค็ม ( TKKHaikhem )**
   - ไฟล์: `TKKHaikhem.ttf` (หรือ `TKKHaikhem.woff2`)
4. **นิทานญี่ปุ่น ( EBMonogatari )**
   - ไฟล์: `EBMonogatari.ttf` (หรือ `EBMonogatari.woff2`)
5. **ขี้เกียจบ่น ( LBLazytocomplain )**
   - ไฟล์: `LBLazytocomplain.ttf` (หรือ `LBLazytocomplain.woff2`)
6. **KanchaEasy**
   - ไฟล์: `KanchaEasy.ttf` (หรือ `KanchaEasy.woff2`)
7. **KanchaEmpty**
   - ไฟล์: `KanchaEmpty.ttf` (หรือ `KanchaEmpty.woff2`)
8. **ยุนอา ( SOV_Yoona )**
   - ไฟล์: `SOV_Yoona.ttf` (หรือ `SOV_Yoona.woff2`)

> หมายเหตุ: หากยังไม่ได้วางไฟล์ฟอนต์ ระบบจะมี Fallback อัตโนมัติไปยังฟอนต์ 'Prompt' เสมอ ทำให้เว็บไซต์ยังคงแสดงผลได้สวยงามตามปกติ ไม่พัง
